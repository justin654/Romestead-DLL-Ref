How The Terminal Works

Open GameTerminal type

Default mode

Non-dot input is sent to Lua. Dot input strips the leading . and runs through Candide.Terminal.GameTerminal.DoCommand(string) after stripping the leading dot.

Registry

Commands are registered in Candide.CandideEngine.AddTerminalCommands() and stored in Candide.Terminal.GameTerminal.Commands: Dictionary<string, TerminalCommand>.

Autocomplete

Tab completion uses Candide.Terminal.GameTerminal.SuggestCommand(string), using Commands.Keys plus per-command suggestion delegates. Argument completion appears only when the command provides a suggestion delegate.

Debug Mode Notes

  • .debuggeneral toggles Candide.Globals.Debug.
  • Several debug-only UI paths are gated behind Globals.Debug; availability depends on the current game screen and state.
  • PlayerInventoryWindow creates the debug item browser when Globals.Debug, cheats, and inventory extensions are enabled.
